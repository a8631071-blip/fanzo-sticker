公開靜態貼圖 Prompt 生成器｜1027V1｜本機測試版

1. 解壓縮 ZIP，進入 prompt 資料夾，雙擊 index.html 即可使用。
2. 選擇文字主題，共 20 種；每主題 60 句、分三批，每批 20 句。
3. 文字可自行修改，選擇角色描述、參照方式、畫風與字體風格後按「重新生成」或「複製 Prompt」。
4. 「有母圖」模式：請在實際使用的 AI 生圖平台另外上傳角色母圖；本工具不會上傳圖片。
5. 本工具只產生文字指令，不會直接生圖、不會自動驗證 AI 生圖結果。
6. 編輯內容只保存在目前開啟的頁面記憶體，重新整理會回復原始 60 句；不需登入或網路伺服器。

公開資料：20 個主題 × 60 句＝1200 句，20 個字體風格描述。
公開資料範圍：僅包含本版選定的 20 組、每組 60 句，未附加其他主題或私人資料庫。
此測試 ZIP 完全獨立，並未部署到 GitHub 或公開網站。
