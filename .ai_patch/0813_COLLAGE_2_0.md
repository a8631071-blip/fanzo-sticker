# 素材拼板 2.0｜公開版工程日誌

## 基底
- 唯一基底：GitHub `main` 的 `/collage/` 公開版（原頁面標示 `0805V3`）。
- 私人版 `素材拼板工具_0812V27` 僅作自由物件互動機制參考，未直接覆蓋或移植私人模組。

## 本次修改
- `collage/index.html`
  - 公開頁面標示更新為「素材拼板 2.0」。
  - 新增排列方式：`制式格排列`／`自由排列`。
  - 自由排列僅提供：新增文字、清空版面、清空素材。
  - 選取自由物件後提供最小控制：旋轉角度、置頂、置底、刪除。
  - 文字只提供：內容、黑體／明體／等寬、大小、顏色、粗體。
- `collage/app.js`
  - 原 `cells[]` 制式格資料與流程保留。
  - 新增獨立 `freeObjects[]`，不把自由物件塞回格子模型。
  - 圖片自由物件支援：拖曳、等比縮放、旋轉、置頂／置底、刪除。
  - 文字自由物件支援：拖曳、縮放、旋轉、基本文字設定、置頂／置底、刪除。
  - 制式格／自由排列各自保留內容，切換不互相覆蓋。
  - 自由物件採畫布比例座標，畫布縮放或輸出尺寸改變時維持相對位置。
  - 預覽與 PNG 匯出共用相同的自由物件繪製函式。
  - 自由排列輸出尺寸不受先前格子欄列數影響。
- `collage/styles.css`
  - 新增自由物件選取框、縮放控制點、旋轉控制點與最小文字控制 UI。
  - 保留原公開版深色介面與素材區浮動面板架構。

## 風險點
- 公開版自由排列刻意只做基礎功能，不支援裁切、自由拉寬拉高或進階文字效果。
- 文字字型只使用瀏覽器／系統可用字型；不同作業系統可能有字型 fallback 差異。
- GitHub Pages 實際對外更新時間由 GitHub 部署流程決定；本日誌只確認 `main` 原始碼已更新。
