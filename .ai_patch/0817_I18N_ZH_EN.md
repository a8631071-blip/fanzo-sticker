# 0817｜公開版繁中／英文 i18n 第一階段

## 基底
- main 於 2026-08-17 的公開版。
- 保留首頁、去背切割、LINE 上架檢查、QR、素材拼板 2.0 既有功能與資料流。

## 修改
- 新增 `assets/i18n.js` 共用語言核心。
- 首頁與四套工具接上同一套 `zh-TW / en` 切換。
- 語言選擇寫入 localStorage；首次依瀏覽器語言判定，中文瀏覽器用繁中，其餘先回英文。
- 靜態 UI、aria/title/placeholder、meta、主要動態狀態、alert/confirm 共用翻譯。
- 語言切換器依頁面路徑掛載到既有標頭／資訊區，不使用全站固定右上浮層。
- sticker 手機版隱藏版本日期的 CSS 已限縮在 sticker 頁，不影響其他工具。
- LINE 商品正式名稱、商品說明與作品圖片 alt 視為作品內容，保留原文，不因 UI 語言切換改名。
- 素材拼板新增文字的預設內容會依目前語言顯示「輸入文字 / Enter text」。

## 未修改
- 不改去 Gemini 浮水印、傳統去背、魔術棒、切割、Main/Tab、ZIP 核心。
- 不改 LINE 上架檢查 PNG/APNG/ZIP 解析核心。
- 不改 QR 編碼／繪製核心。
- 不改素材拼板拖曳、縮放、旋轉、匯出核心。
- 本階段不加入日文、泰文。

## 驗收
- `node --check assets/i18n.js`：PASS。
- 首頁、sticker、line-check、QR、collage 五頁以 headless Chrome 實際開啟英文模式：PASS。
- 五頁皆確認語言切換器存在、`html lang=en`、主要英文 UI 已生效，且未出現 SyntaxError / ReferenceError / TypeError：PASS。
- 五頁英文模式可見 UI 殘留繁中文字掃描：PASS（LINE 作品正式名稱／說明／作品圖片 alt 明確排除，因其屬作品內容而非介面）。
- 五頁逐頁執行 `English ↔ 繁中` 雙向切換：PASS。
- 五頁逐頁確認 localStorage 記憶語言，重新整理後仍維持 English：PASS。
- 雙向驗收第一次失敗原因為測試控制器接到錯誤 Chrome target；改為直接鎖定本站 page target 後五頁全數 PASS，網站程式本身未因該次失敗而降級驗收標準。

## 風險與防護
- 不採四份 HTML，避免未來功能版本不同步。
- 語言切換器不使用全站固定右上浮層，避免遮住 sticker 更新日期與 line-check 工具列。
- i18n 內建 `?i18nAudit=1` 可列出英文模式仍殘留的未翻譯 UI。
- 作品正式名稱／說明不翻譯，避免自行改動已上架 LINE 商品名稱；未來若要做作品區多語資料，應獨立處理，不混進 UI i18n。
