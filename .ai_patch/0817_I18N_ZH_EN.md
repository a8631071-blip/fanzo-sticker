# 0817｜公開版繁中／英文 i18n 第一階段

## 基底
- main 於 2026-08-17 的公開版。
- 保留首頁、去背切割、LINE 上架檢查、QR、素材拼板 2.0 既有功能與資料流。

## 修改
- 新增 `assets/i18n.js` 共用語言核心。
- 首頁與四套工具接上同一套 `zh-TW / en` 切換。
- 語言選擇寫入 localStorage；首次依瀏覽器語言判定，中文瀏覽器用繁中，其餘先回英文。
- 靜態 UI、aria/title/placeholder、主要動態狀態、alert/confirm 共用翻譯。
- LINE 商品正式名稱與商品說明視為作品內容，保留原文，不因 UI 語言切換改名。
- 素材拼板新增文字的預設內容會依目前語言顯示「輸入文字 / Enter text」。

## 未修改
- 不改去 Gemini 浮水印、傳統去背、魔術棒、切割、Main/Tab、ZIP 核心。
- 不改 LINE 上架檢查 PNG/APNG/ZIP 解析核心。
- 不改 QR 編碼／繪製核心。
- 不改素材拼板拖曳、縮放、旋轉、匯出核心。
- 本階段不加入日文、泰文。

## 風險與防護
- 不採四份 HTML，避免未來功能版本不同步。
- 語言切換器不使用全站固定右上浮層，避免遮住 sticker 更新日期與 line-check 工具列；由共用核心掛到各頁既有標頭／資訊區。
- i18n 內建 `?i18nAudit=1` 可列出英文模式仍殘留的未翻譯 UI；工程日誌、作品名稱／說明、素材檔名不列入 UI 漏翻判定。
